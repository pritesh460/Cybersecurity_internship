## Overview

This repository contains the practical modules completed for **Week 3** of the Cybersecurity training.

The primary objective of these modules was to crack the passwords of locked PDF files and extract the hidden flags using both offline and online password-cracking tools.

The project covers two approaches:

* **Module 1:** John the Ripper (JTR) and Johnny GUI
* **Module 2:** Networkwalks Hash Calculator and Password Cracker

Password cracking was performed in a controlled lab environment to understand password strength and password recovery techniques.

# 🔹 Module 1 — Password Cracking with JTR

Recover the password of a protected PDF using **John the Ripper (JTR)** and **Johnny GUI**.

### Steps

**Step 1 — Install JTR and Johnny**

Download and install **John the Ripper (JTR)** and **Johnny GUI** on the Windows system. Open Johnny and configure it to use the `john.exe` file from the JTR installation.

**Step 2 — Extract the PDF Hash and Create the Hash File**

Open the **PDF Hash Extractor** and upload the locked PDF. Copy the complete hash value generated by the tool. The hash should start with `$pdf$`.

Open Notepad, paste the extracted hash, and save the file as:

```text
hash1.txt
```

**Step 3 — Load the Hash in Johnny and Start the Password Cracking Attack**

Open Johnny, select **Open password file**, and load the `hash1.txt` file.

Select **Start new attack** and wait for John the Ripper to identify the matching password. The time required may vary depending on the system and password complexity.

**Step 4 — Verify the Password**

Open the locked PDF and enter the recovered password. Confirm that the PDF opens successfully.

# 🔹 Module 2 — Password Cracking with Networkwalks Tools

Recover the password of a protected PDF using the **Networkwalks Hash Calculator** and **Password Cracker**.

### Steps

**Step 1 — Extract the PDF Hash**

Open the **Networkwalks Hash Calculator** in your web browser and upload the locked PDF.

The tool generates a PDF hash starting with `$pdf$`. Copy the complete hash value.

**Step 2 — Crack the Password**

Open the **Networkwalks Password Cracker**, paste the extracted hash, and start the attack.

Wait for the tool to find the matching password.

**Step 3 — Verify the Password**

Open the locked PDF and enter the cracked password.

In this lab, the recovered password was **`password1`**, and the PDF opened successfully.
